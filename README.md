# AutoPR Sample Repository

A small Python project intentionally designed for testing AutoPR.

## Sample Work Item

**AUTOPR-101 — Add password strength validation**

Requirements:
- Minimum 8 characters
- At least one uppercase letter
- At least one number
- At least one special character

AutoPR should inspect the repository, follow `coding-standards.md`, implement the requirement, update tests, run pytest, and create a pull request.

## Run tests

```bash
pip install -r requirements.txt
pytest
```
